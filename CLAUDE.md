# CLAUDE.md — working on Frank's Computer

- This is a single-file browser game. Edit `src/`, then run `python3 build.py`. Never hand-edit `dist/index.html`;
  it is generated (a prebuilt copy is committed only as a convenience).
- Plain browser JS (ES2020), no modules, no bundler, no npm dependencies. Each app file is an IIFE. The API contract
  every app uses is in `docs/API.md`. Prefix CSS classes per app (`.xl-`, `.oe-`, `.ex-` …).
- `docs/SPEC.md` is the design spec (later "v2…v6" sections override earlier ones). `docs/CANON_DECISIONS.md` holds
  numbers and story facts that must stay consistent across emails, spreadsheets, hints and the packacorp.com site.
  If you change a number, change it everywhere and rerun the tests.
- Links and the end-screen CTA live in `config.json` (injected as `window.FR_CONFIG`). Defaults are in the `CONFIG`
  object at the top of `src/boot.js`.
- Images are base64 in `src/assets.js`. Sounds are base64 in `src/sounds.js`, generated by `tools/make_sounds.py`.
- Player accounts: `src/account.js` (sign-in screen, wraps `FR.save`/`FR.resetSave` to sync `FR.state` to `/api/save`) and
  `api/*.js` (Vercel Node functions, Upstash Redis over REST with `fetch`, no npm dependencies). Everything a player
  does must live in `FR.state` to be saved. Without the API (file://, static host, no database) the game runs browser-only.
  Tests: `node test/account_api_test.js` (ALL PASS) and `python3 test/account_play.py`; `node test/local_server.js` runs it locally.
- Hints are presented as "Datarails FinanceOS" cards. Packa Corp itself does not use Datarails; keep that joke intact.
- Tests: `node test/excel_engine_test.js` must print ALL PASS. `python3 test/play.py` (Playwright, Chromium) plays the
  whole game through the UI and must end with "no console errors".
- `?dev=1` / `?solve=<id>` shortcuts work only on file:// and localhost (see `LOCAL` in `src/boot.js`).
- Deploys: Vercel (`vercel.json`: build → test → serve `dist/`). Pushing to `main` deploys production; `.github/workflows/ci.yml` builds and tests every push.
